📡
Fuentes de Noticias

Obtiene noticias en tiempo real desde NewsAPI (Bloomberg, Reuters, medios chilenos). Con fallback automático a RSS feeds si hay fallas de conexión.

🤖
Análisis Automático

Cada noticia recibe un score de impacto (1-10) basado en palabras clave estratégicas. Las alertas críticas (score ≥ 8) se destacan automáticamente.

📧
Envío por Email

El newsletter completo se envía automáticamente por email cada vez que se genera una nueva edición. Configurable vía GitHub Secrets.

⚡
Automatización con GitHub Actions

El workflow se ejecuta cada 6 horas automáticamente, generando y publicando la nueva edición sin intervención manual.
